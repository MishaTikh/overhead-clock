OVERHEAD for the Ulanzi TC001 clock
===================================

To install or update: double-click  Install-Overhead.bat

  - If Windows asks "Are you sure you want to run this file?", click Run.
    (Or "More info" and then "Run anyway".) The installer is a small script;
    Windows shows that for anything downloaded from the internet.
  - Your PC and the clock must be on the same Wi-Fi.
  - A clock already running Overhead will ask for its admin password:
    hold the clock's middle button for 3 seconds to see it.

Full instructions and help:  https://mishatikh.github.io/overhead-clock/
Project page:                https://github.com/MishaTikh/overhead-clock

Files in this folder:
  Install-Overhead.bat      the installer (double-click this one)
  install-overhead.ps1      the installer's code, which the .bat runs
  overhead-tc001-app.bin    the firmware it installs
